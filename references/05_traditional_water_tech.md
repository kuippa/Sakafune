# 05 水にまつわる伝統の技術・道具

水の計算装置を「原始的な素材（石・土器・木・竹・銅）と度量衡で作れる範囲」に収めるための参考集です。日本の技術を中心に、関連の深い海外の例も入れています。

- 各項目に、**計算の部品として何に使えそうか**を書いています（💭 は本プロジェクトの解釈）。
- 確認状況の記号は [README.md](README.md) を参照。このファイルでは主に 🔍（Web上の解説・二次資料で概要を確認、一次資料は未読）を使っています。
- 作成：Claude Opus 5.5（2026-10-10）。調査のきっかけ：kuippa（両升が「オーバーテクノロジー」ではないかという指摘）

## 一覧：計算の部品との対応 💭

| 計算に要る働き | 使えそうな伝統技術 |
|---|---|
| 決まった量を量る（量子化・単位） | 升（度量衡）、計量の器、漏刻 |
| 水平・同じ高さを出す（しきい値をそろえる） | 水盛り（水準） |
| 均等に分ける（分岐） | 円筒分水、三分一湧水の三角石 |
| しきい値を超えたら全部出す | 教訓茶碗・公道杯（サイフォン）、添水・ばったり（傾いて空になる）、欹器（満ちると覆る） |
| 状態を持つ（記憶・向き） | 欹器（空・半分・満の3つの状態）、転倒升 |
| 谷を越えて運ぶ（配線） | 筧・樋、逆サイフォン（伏越） |
| 水を持ち上げる（電源・ループ） | はねつるべ、踏車、竜骨車 |
| 水位差で押し出す | 噴水（兼六園） |

## 1. 量る：度量衡と計量

### 🔍 升と度量衡（大宝律令 701年）
- 日本で長さ・容量・重さの単位が初めて全国で統一されたのは大宝律令（701年）とされる。それ以前は地域で単位が違った。大宝令・養老令では「大」と「小」の2系統の単位があり、大尺は小尺の1.2倍。
- 容量は 石・斗・升・合 の10進（10升＝1斗、100升＝1石）。
- 出典（概要）：https://hugkum.sho.jp/533035 、https://projects.mcah.columbia.edu/jaanus/node/1120
- 💭 計算での役割：**「1u」を社会的に共有された単位として決められる**。飛鳥時代末にはすでに国家の単位があった。

### 🔍 京枡（寛文9年＝1669年の統一）
- 江戸幕府が内のり 4寸9分四方・深さ 2寸7分（容積 64,827 立方分）と定め、江戸と京都の枡座で製造・販売・検査（枡改め）を管理した。
- 出典（概要）：https://kotobank.jp/word/%E4%BA%AC%E6%9E%A1-53050
- 💭 役割：器の寸法から容量を決め、検査で揃える仕組みそのものが、計算装置の「部品の規格」に当たる。

### 🔍 水盛り（水準）
- 長い木の溝に水を張り、水面を基準に土台や梁の水平を出す、大工の伝統的な方法。鎌倉時代の絵巻に描かれているとされる。水を入れた管の両端の水面は同じ高さになる（連通管の原理）。
- 出典（概要）：https://motitown.com/vocabulary/ja/%E6%B0%B4%E5%B9%B3%E5%99%A8
- 💭 役割：**しきい値（穴・溢れ口・サイフォンの頂点）の高さを、離れた器どうしで正確に揃える**のに使える。

### 🔍 漏刻（水落遺跡、斉明6年＝660年）
- 『日本書紀』に、皇太子の中大兄皇子が初めて漏刻を作ったとある。その跡とされる飛鳥水落遺跡では、石貼りの基壇の内部に木樋が通り、基壇の中央に漆塗りの木箱が据えられていた。
- 出典（概要）：https://tabi-mag.jp/na0042/ 、奈良文化財研究所の報告（https://sitereports.nabunken.go.jp/ja/article/10555/pdf_page ）
- **注意**：「U字型の銅管をサイフォンとして使った」という記述は村上ら2017 によるもので、今回の検索では一次報告での確認ができなかった。❓
- 💭 役割：一定の流量を作る（クロック）。飛鳥時代の技術水準の基準線。

## 2. 分ける：分水

### 🔍 円筒分水（久地円筒分水、1941年）
- 二ヶ領用水の水を4つの堀に公平に分けるための設備。水を平瀬川の下にくぐらせ、円筒の中で噴き上げて、縁の円周の比で分ける。それ以前の「久地分量樋」では正確に分けられず、水争いが絶えなかった。1998年に国の登録有形文化財。同じ方式の円筒分水が全国に作られた。
- 出典（概要）：https://www.library.city.kawasaki.jp/images/upload/path2_entou.pdf 、https://online.bunka.go.jp/heritages/search/item_176746:1
- 💭 役割：**分水口**。流れる量が変わっても割合が変わりにくい。ただし作られたのは近代（コンクリート）。原理（下から湧かせて縁で溢れさせる）は原始的な素材でも作れそう。

### 🔍 三分一湧水（山梨県北杜市）
- 湧き水をめぐる水争いを収めるため、分水池の中央に三角石を置き、3方向へ均等に分けた。武田信玄が三角石柱を立てたという伝承がある。江戸時代までは木の枠の水門、大正時代に石造りの分水池になり、昭和18年の土石流で流された後に作り直されたものが現在のもの。
- 出典（概要）：https://tabi-mag.jp/yn0137/ 、https://www.pref.yamanashi.jp/documents/63240/6kouki17-p89.pdf
- 💭 役割：**石の仕切り1つで均等に分ける**。石で作れる分水口の例。

## 3. 溜めて、しきい値を超えたら出す

### 🔍 添水（そうず）・鹿威し
- 竹筒に水を引き入れ、満ちると重みで傾いて水がこぼれ、軽くなると元に戻る。戻るときに石を打って音を出す。もとは田畑を荒らす鳥獣を追い払う農具で、のちに音が風流とされて庭園に置かれるようになった。
- 出典（概要）：https://precious.jp/articles/-/3289
- 💭 役割：**溜めて、満ちたら全部出して元に戻る**。サイフォン（教訓桝）と同じ働きを、管を使わずに竹1本と支点で実現できる。周期的に動くのでクロックにもなる。

### 🔍 ばったり（添水唐臼）
- 水受けに落ちる水の重みで、てこの先の杵を上げ下げし、米をつく。添水と同じ原理を動力として使う民具。
- 出典（概要）：https://www.city.chofu.lg.jp/documents/2358/jindaiji_suishakan.pdf
- 💭 役割：**傾く器は農村の道具として広く作られていた**。1方向に傾く器（添水・ばったり）は原始的な技術の範囲と言える。

### 🔍 教訓茶碗・公道杯（ピタゴラスカップ）
- 中国の九龍公道杯は、明の永楽年間に景徳鎮の官窯で作られたとされる。浅く注ぐ分には使えるが、一定の高さを超えて注ぐとサイフォンで中身が全部漏れ出る。
- 出典（概要）：https://m.thepaper.cn/newsDetail_forward_2004498 、https://melscience.com/GB-en/articles/greedy-cup/
- 💭 役割：**教訓桝そのもの**（設計01）。

### 🔍 欹器（きき）・宥坐の器
- 『荀子』宥坐篇に、孔子が魯の桓公の廟で見たと記される器。**空なら傾き、半分なら真っすぐ立ち、満ちると覆って中身を出す**。中庸の教えのたとえ。
- 出典（概要）：https://en.wikipedia.org/wiki/Qiqi_(tilting_vessel) 、原文 https://zh.wikisource.org/wiki/%E8%8D%80%E5%AD%90/%E5%AE%A5%E5%9D%90%E7%AF%87
- 💭 役割：**3つの状態を持ち、満ちると全部出す器**。サイフォンの管なしで「しきい値で全部出す」ができ、しかも空・半分で向きが変わるので、状態を外から読める。紀元前の文献に出てくる、とても古い仕掛け。

### 🔍 転倒升式雨量計（1662年）
- 1662年、英国のクリストファー・レンがロバート・フックと協力して作ったとされる、最初の転倒升式雨量計。決まった量が溜まると升が傾いて空になり、その回数で雨量を記録する。
- 出典（概要）：https://en.wikipedia.org/wiki/Rain_gauge 、https://i.cs.hku.hk/~rain/RainGauge-English.php
- 💭 役割：設計02・03の**両升**の、記録に残る最も古い例の一つ。両升（左右に升がある形）をこの時期以前の日本や飛鳥時代に求めるのは、根拠が乏しい。**1方向に傾く添水・ばったりで代わりが利かないか**を先に考えるべき → [設計04](../design/04_sozu-xor.md) で、添水1つの XOR を作った。

### 💭 記録に残らない「現象としての利用」について（kuippa のコメント）
- サイフォンの原理を習う前でも、目端の利く子どもならたどり着く。竹の水鉄砲や藁のストローで水が外へ出てしまう現象は、昔の人も確認していたはずで、記録がなくても、現象として利用した人がいても不思議ではない。
- 本プロジェクトの方針：これは推論（💭）として扱い、設計では記録で裏付けられる部品で代わりが利くなら、そちらを優先する。

## 4. 運ぶ・越える・持ち上げる

### 🔍 筧・樋（竹樋・木樋・石樋）
- 竹・木・石で作った水路。酒船石の周辺でも、土管と石樋（東約40m）、導水用の「車石」が見つかっている（[01_archaeology.md](01_archaeology.md)）。
- 💭 役割：**配線**。

### 🔍 通潤橋（熊本県山都町、1854年）
- 白糸台地に水を送るための、日本最大級の石造アーチの水路橋。橋の上の3本の石管を、逆サイフォン（連通管の原理）で水が通る。上流側で 7.5m 下り、下流側で 5.8m 上る。
- 出典（概要）：https://www.maff.go.jp/j/nousin/sekkei/museum/m_kakuti/59_tuujyu/index.html 、https://en.wikipedia.org/wiki/Ts%C5%ABjun_Bridge
- 💭 役割：**石の管で、谷を越えて水を運べる**。管の中を満たして流す技術は、石工の技術の範囲。

### 🔍 辰巳用水（金沢、1632年）
- 加賀藩主前田利常の命で、町人の板屋兵四郎が造ったとされる約11kmの用水。下流部では、地中に埋めた木管の逆サイフォンで、兼六園側から堀を越えて金沢城二の丸へ水を上げた。2018年に土木遺産。
- 出典（概要）：https://committees.jsce.or.jp/heritage/node/1014 、https://www.jsce.or.jp/branch/chubu/isan/top/img/poster/poster_photo27.pdf
- 💭 役割：**木の管でもサイフォンが実用になっていた**例。

### 🔍 兼六園の噴水（1861年）
- 日本最古とされる噴水。動力を使わず、霞ヶ池の水面との高さの差による水圧で噴き上がる。高さは約3.5mで、池の水位で変わる。金沢城二の丸へ水を引くための試作だったとも言われる。
- 出典（概要）：https://www.travelbook.co.jp/topic/706/
- 💭 役割：**水位差＝蓄えた力**。高い所に溜めた水が、計算装置の「電源」になる。

### 🔍 はねつるべ（桔槔）
- 支柱の上に横木を渡し、一方に桶、反対側に重しの石を付けて、井戸の水を汲む。日本では江戸時代に浅い井戸で使われた。てこで汲み上げる仕組み自体は古く、各地にある。
- 出典（概要）：https://ja.wiktionary.org/wiki/%E3%81%A4%E3%82%8B%E3%81%B9
- 💭 役割：**人が水を持ち上げる（ループ・電源）**の道具。

### 🔍 踏車（ふみぐるま）・竜骨車
- 踏車は寛文年間（1661〜1672年）に大坂の京屋七兵衛が発明したとされる、人が羽根を踏んで回す揚水機。それ以前の竜骨車（多数の板を鎖のようにつないだ揚水機）は故障が多く、2人がかりだった。
- 出典（概要）：https://kotobank.jp/word/%E8%B8%8F%E8%BB%8A-125762 、https://www.mlit.go.jp/river/pamphlet_jirei/kasen/rekishibunka/kasengijutsu15.html
- 💭 役割：水を持ち上げる（電源）。ただし時代は近世。

## 5. 音・庭の水

### 🔍 水琴窟（洞水門）
- 地中に伏せて埋めた甕の底の穴から水滴が落ち、甕の中で響く。もとは手水鉢の排水の仕掛けとされ、江戸時代中ごろに広まった。小堀遠州が考案者とされることが多い。
- 出典（概要）：https://en.wikipedia.org/wiki/Suikinkutsu
- 💭 役割：直接の計算部品ではないが、**伏せた甕と穴で水の通り道を作る**技術。

### 飛鳥の石造物（須弥山石・石人像）
- 内部が空洞で、水を溜めると下の穴から噴き出すと考えられている（村上ら2017、[01_archaeology.md](01_archaeology.md)）。
- 💭 役割：飛鳥時代に、**石の内部に水の通り道を彫り、水位差で噴き出させる**技術があった。

## 6. この調査から設計へ 💭

1. **両升は後回しにする**。記録に残る最古の例は1662年の英国。飛鳥時代の部品としては根拠が乏しい。
2. **1方向に傾く器（添水・ばったり）と欹器**は、古くからある。特に欹器は「満ちると覆って全部出す」「空・半分で向きが変わる」ので、サイフォンの管なしで、しきい値・全部出す・状態の3つをこなせる候補。
3. **分水は石の仕切りで足りる**（三分一湧水）。円筒分水の原理は、湧かせて縁で溢れさせる形にすれば、原始的な素材でも作れそう。
4. **しきい値の高さを揃える**には水盛りが使える。**単位（1u）**は升の度量衡で共有できる。
5. **持ち上げ（ループ）**は、はねつるべのような、てこの道具で担える。

## 要調査
- 欹器の日本での受容（いつ伝わり、実物が作られたか）
- 添水・ばったりの日本での古い記録（何時代までさかのぼれるか）
- 水落遺跡の銅管の有無（一次報告での確認）
- 飛鳥時代の升の実物・容量
