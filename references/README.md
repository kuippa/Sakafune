## 確認状況の記号

文献の書誌情報（著者・年・掲載誌・ページなど）を、どこまで確かめたかを記号で示しています。

| 記号 | 意味 |
|---|---|
| ✅ | 本文または公式ページを読んで確認済み |
| 🔍 | Web上の解説・二次資料で概要を確認（一次資料は未読） |
| 📘 | よく知られた文献で、書誌はほぼ確実。ただし本プロジェクトでは本文を未確認 |
| ❓ | 書誌の一部が未確認。引用する前に原典で確かめる必要あり |

## 運用ルール

- 論文PDFなど第三者の著作物は、このリポジトリに入れません。URL・DOIだけを載せます。
- 新しい文献は、該当する分野のファイルに追記します。分野をまたぐ文献は主な分野に書き、ほかのファイルからは参照だけにします。
- 本文で数値や事実を使ったら、どの文献のどこから取ったかを「使いどころ」に書き残します。
