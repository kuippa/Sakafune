# 酒船石チューリング計算装置仮説：研究引き継ぎメモ

## 1. コア仮説

奈良県明日香村の酒船石（岡の酒船石）は、単なる祭祀施設・酒造施設ではなく、**流体論理を用いた計算装置（またはその入出力ノード）**だった可能性がある。

---

## 2. 考古学的制約（変更不可の事実）

| 項目 | 数値・状態 |
|------|-----------|
| 石材 | 花崗岩 |
| 寸法 | 東西約5.5m × 南北約2.3m × 厚さ約1m |
| 主軸 | ほぼ東西方向 |
| 傾斜 | 東から西へ約5.5度傾斜 |
| くぼみ | 円形・楕円形6箇所（深さ約10cm）＋ 中央長楕円形1箇所（1.35m×0.7m） |
| 溝 | くぼみ間を結ぶ細い溝が存在 |
| 欠損 | 北側・南側の一部が欠損（高取城石垣転用説） |
| 周辺遺構 | 亀形石造物・小判形石造物・導水施設・700m以上の石垣・版築造成 |

---

## 3. コンピュータアーキテクチャ的読解

### 3.1 各構造の仮想的役割

| 構造 | 仮想的役割 |
|------|-----------|
| 周囲の小さな円形くぼみ（6箇所） | 並列入力レジスタ / 入力ポート群 |
| 中央の長楕円形大くぼみ | アキュムレータ / 統合演算器 / 状態保持部 |
| くぼみ間の溝 | 配線（バス） / 信号伝達路 |
| 楕円配置の溝 | 等時性配線（各入力から中央への到達時間均等化） |
| 北・南の欠損部 | 入出力ポート / ループバック接続口（破損ではなく設計の可能性） |
| 亀形石造物（北方谷部） | 下流側の出力デバイス / 次段モジュール |

### 3.2 D3の特殊性

- D1〜D6のうち、**D3だけが配置・接続パターンから「浮いている」**ように見える
- 仮説的役割：
  - (a) キャリー出力ポート（桁上り信号の出力）
  - (b) ループバック制御口（循環の起点）
  - (c) 次段（亀形石造物）への接続点
- 「浮いている」＝識別可能性の物理的マーカーとして機能していた可能性

## 4. チューリング完全性の必要条件と酒船石の対応

| チューリング機械の要素 | 酒船石単体での有無 | 付属構造追加で実現可能か |
|---------------------|----------------|----------------------|
| 記憶（無限テープ） | ×（有限のくぼみのみ） | ○（多段タンク・導水管の積層） |
| 読み書きヘッド | △（液面の視覚観測） | ○（浮き物・栓機構の追加） |
| 状態遷移（プログラム） | △（溝の分岐構造） | ○（バルブ・重量弁の追加） |
| 条件分岐 | △（溢れ・溝の振り分け） | ○（閾値検出機構の明確化） |
| ループ（反復） | ×（現存構造では一方通行） | ○（欠損部への導水管・ポンプ・戻り路） |
| クロック（同期） | × | ○（外部からの周期的注水） |

**結論**：酒船石単体ではチューリング完全ではないが、**失われた上方向構造（木造・竹・導水管）とループバック経路を復元すれば、チューリング完全な流体計算装置の入出力ノードとして機能しうる**。

---

## 5. 桁上り（キャリー）の構造論

- 1桁目の加算：半加算器（Half Adder）で実現可能。キャリー入力不要。
- **2桁目以降：全加算器（Full Adder）が必須**。前桁のキャリーを受け取る構造が必要。
- 酒船石の7〜8個のくぼみは1桁の半加算器レベルには対応するが、多桁の繰り返しパターンが見られない。
- 多桁演算を行うには**上方向（Z軸）の多段構造**が必須。

## 7. 未解決問題（次の研究者・AIへの課題）

1. **D3の実地確認**：D3と他のD群の溝の太さ・傾斜・深さ・加工痕の比較調査
2. **欠損部周辺の地中レーダー探査**：導水管痕跡の有無
3. **亀形石造物との高低差・距離関係の精密測定**：パイプライン接続の実証
4. **流体論理シミュレーション**：酒船石の3Dモデル＋流体力学計算による動作検証
5. **チューリング完全性のスケッチ証明**：条件分岐とループの物理実装を具体化し、少なくとも「任意のチューリング機械をシミュレートできる」ことを示す
6. **計算例の具体化**：1+1（半加算器）、2ビット加算（全加算器）、1ビット記憶（RSフリップフロップ）のいずれかを手順化

---

## 8. 設計上の自由度（仮説追加可能な要素）

- 上方向（Z軸）の多段タンク（木造・竹・石積み）
- 失われた導水管・バルブ・栓（有機材料なので腐朽・破壊）
- 液体の物性利用（粘性・比重・表面張力）
- 人間の操作（プログラムとしての栓開閉・注水タイミング制御）
- 圧力駆動型論理（蓋・密封構造による空気圧・水圧スイッチング）

---

## 9. 制約条件（設計上のルール）

1. 考古学的に確定している寸法・配置・傾斜は変更しない
2. 失われた部分の復元は「飛鳥時代の技術水準で実現可能な範囲」に限定
3. チューリング完全性の主張はスケッチレベルで論理的整合性を確認する
4. ハルシネーション（虚構の事実の捏造）を排し、推論の範囲内に留める
