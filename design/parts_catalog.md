# 部品カタログ（機能で定義する）

- 作成：Claude Opus 5.5（`claude-opus-5-5`）、2026-11-08。方針：kuippa（名前ではなく、機能で部品化する）
- 状態：💭 定義。設計10（フォールモデル）から使う。設計01〜09 の名前との対応は §6
- バージョン：v1.0 の部品（v2 で部品を足すときは、この表に追記し、足した版を書く）

---

## 1. 考え方

- 部品は「何でできているか」ではなく、**「水に何をするか」**で定義する。同じ機能の部品は、どの素材・どの形で作ってもよい（実体の候補は §5）。
- 部品には **口（ポート）** がある。口は2種類だけ。
  - **水口**：水が出入りする口。入口（in）と出口（out）がある。**水路は必ず、高い出口から低い入口へつなぐ**（フォールモデルの決まり）
  - **軸口**：竿の傾き（状態）を、別の部品へ機械的に伝える口。水は通らない。上下どちらへもつないでよい
- 量の単位は u（1u ＝ 決めた量の水。例：100mL）。

## 2. 基本部品（10種類）

| 記号 | 部品名 | 働き | 口 | 決める値 |
|---|---|---|---|---|
| **SRC** | 電源槽 | 水面の高さを一定に保ち、一定の速さで水を出し続ける | out | 流量 |
| **SNK** | 捨て槽 | 受けるだけ。計算に使わない水の行き先 | in | ― |
| **CLK** | 拍発生器 | 一定の流れを受け、P u たまるたびに、まとめて出す（クロック） | in, out | P（1拍の量） |
| **MTR** | 定量升 | 入った水を V u まで受け、それを超えた分は溢れ口から出す。決まった時（開けたとき・次へ送るとき）に V u を出す | in, out, 溢れ口 | V |
| **SPL** | 量り分け器 | 入った水を、決めた量 v₁, v₂, … に分けて、それぞれの出口へ出す。残りは溢れ口へ（定量升を溢れでつないだ列） | in, out₁…outₙ, 溢れ口 | v₁…vₙ |
| **DLY** | 遅延升 | 入った水を、τ だけ遅らせて出す（小さな穴でゆっくり落とす） | in, out | τ |
| **ACC** | 蓄積升 | 入った水をためるだけ。重さが値になる | in, 重さ（比較器へ） | 容量 |
| **CMP** | 比較器 | 2つの蓄積升（＋側・−側）の重さを比べ、状態を軸口に出す | ＋側, −側, 軸口 | 不感帯 d、おもり o |
| **RTE** | 振り分け器 | 入った水を、軸口から来た状態で選んだ1つの出口へ流す | in, 軸口, out₁…outₙ | 出口の数 n |
| **PIPE** | 水路 | 部品の水口どうしをつなぐ。高い所から低い所へだけ | ― | ― |

### 比較器（CMP）の状態
- 重さの差 D ＝（＋側）−（−側）− o（o はおもり。−側に載せる）
- **3状態**（o ＝ 0、不感帯 d ＝ 0.5u）：D ≥ d →「＋」、|D| < d →「0」、D ≤ −d →「−」
- **2状態**（o ＝ 0.5u、不感帯なし）：D > 0 →「≠0」、D < 0 →「0」（値が 0 か 1 以上かだけを見る）
- **目盛り**（傾きの量を読む）：D の値そのもの（受け口の位置で 0, 1, 2, … を区別する）

## 3. 組み合わせ部品

| 記号 | 部品名 | 中身 | 働き |
|---|---|---|---|
| **REG** | レジスタ | ACC＋（＋升）、ACC−（−升）、CMP（2状態） | 値 ＝ ＋升 − −升。**INC口**（＋升へ 1u）で 1 増え、**DEC口**（−升へ 1u）で 1 減る。軸口に「0 / ≠0」を出す。水は足すだけ |
| **OUT** | 出力桶 | ただの桶（ACC 1つ。比較器も−升もない） | 水を受けるだけ。値 ＝ 中の水の量（u）。「0 か」の判定（JZ）で読まれないレジスタ（答え・商など）はこれでよい。人が水位を見て答えを読む |
| **CNT** | 計数添水 | 1u で傾く添水（鹿威し） | 一定の流れを 1u ずつに区切り、傾くたびに音（カコン）を出す。人が回数を数えられる。入力（元栓管理係が数える）と評価（カウント係が数える）に使う。CLK は CNT 3回分。v2（設計11 §6.2）で追加 |
| **INP** | 入力器（別案） | MTR（1u）を溢れでつないだ列 ＋ 仕切り（ペグ）＋ 一度に開ける栓 | 仕切りを目盛り n に差すと、先頭から n 個の升だけが満ちる（先は捨て槽へ）。栓を開けて、n u をレジスタの＋槽へ送る。v2（設計11 §6.1）。今は CNT＋元栓管理係の入力を使い、こちらは別案として残す |
| **PCR** | 手番レジスタ | REG（CMP は目盛り）＋ あふれ止め（下記） | いま実行する命令の番号 k を持つ。軸口に k を出す |
| **DCD** | デコーダ | PCR の軸口 ＋ RTE（n 方向） | 入った水を、命令 k の駅へ流す |
| **STN-INC** | 駅：INC r → next | SPL（1u と \|next − k\| u）＋ DLY | 1u を r の INC口へ。\|next − k\| u を手番レジスタの＋升（進む）か−升（戻る）へ |
| **STN-JZ** | 駅：JZ r → z / nz | RTE（r の軸口で2方向）＋ SPL ×2 ＋ DLY | r ＝ 0 なら \|z − k\| u を手番レジスタへ。r ≠ 0 なら 1u を r の DEC口へ、\|nz − k\| u を手番レジスタへ |
| **STN-HALT** | 駅：停止 | PIPE → SNK | 入った水は捨て槽へ。状態は変わらない（自然に止まる） |

### あふれ止め（PCR の異常停止）
止まらない計算（例：1 ÷ 0）を、水が尽きる前に止めるしくみ。部品を足すだけで、水は上から下へ流れる。
- PCR の−升に、容量 C の**溢れ口**をつける。
- 溢れた水は、同じ竿の**＋側に、−升より低く吊った「あふれ受け」（ACC）**へ落ちる。重さは＋側に掛かる。
- −升が満ちると、「戻る」ための水がすべて＋側に掛かるので、手番は**進むだけ**になる。
- DCD の振り分け器の端（駅の数 n の位置）に、**異常停止の出口**（→ SNK）をつける。手番がここに達すると、拍の水は捨て槽へ流れるだけになり、止まる。
- あふれ受けに水が入っていれば（あふれ印）、答えは**無効**。手番が途中で停止の駅に着いて止まった場合も同じ。
- C は「どれだけ長い計算を許すか」を決める（ふつうの計算で−升に溜まる量より大きくする）。四則演算で a, b ≤ 9 なら最大 279u なので、C ＝ 400u。

## 3.5 人の役割（v2、設計11 §6.2）

装置を動かす人も、役割として決めておく。人がするのは「水を注ぐ」「数える」「決まった順に樋・栓・レバーを動かす」だけで、計算の途中の判断はしない。

| 役割 | すること | いつ |
|---|---|---|
| **給水係** | 電源槽（SRC）へ水を注ぐ。水を高い所へ上げる＝装置の動力 | ずっと |
| **元栓管理係** | ① 切り替えレバーを倒す ② 元栓を開ける ③ 計数添水（CNT）の音を数え、a 回は a の＋槽へ、b 回は b の＋槽へ、そのあとは CLK へ樋を向ける（入力）④ 停止したら元栓を閉める | 準備・入力・停止 |
| **カウント係** | 停止後、水の入っている答えの桶の栓を開け、評価用の計数添水が傾く回数を数える。どちらの桶から流れたかで正負を読む（評価） | 停止後 |

- 計算中（入力のあと、停止まで）は、人は見ているだけ。
- 元栓管理係の「停止したら閉める」は、閉めなくても答えは変わらない（拍の水が捨て槽へ流れ続けるだけ）。

## 4. 決まり

1. 水路（PIPE）は、高い出口から低い入口へだけつなぐ。上へ水を運ぶ部品はない。
2. 状態を持つのは蓄積升（ACC）だけ。ほかの部品は、1拍が終わると空になる。
3. 蓄積升へ入る水は、必ず遅延升（DLY）を通す。拍の水が振り分け器を通り終わってから、比較器の状態が変わるようにするため。
4. 比較器の状態を使う振り分け器は、比較器と軸口でつなぐ。1つの比較器に、振り分け器をいくつつないでもよい（判定は写せる。設計06）。
5. 量り分け器の量の合計 ≤ 拍発生器の P。足りない分を出してはいけない（余りは溢れ口から捨て槽へ）。

## 5. 実体の候補（どう作るか）

| 記号 | 実体の候補 | 確かさ |
|---|---|---|
| SRC | 漏刻の水槽（段になった水槽で水面を一定に保つ）。飛鳥の水落遺跡（660年） | ✅ 漏刻は史実。細部は ❓ |
| SNK | 溝・甕 | ― |
| CLK | 添水（鹿威し）／教訓桝（サイフォン） | 添水 🔍、サイフォンは 💭 |
| MTR | すり切りの升（縁の切り欠きが溢れ口）／小判形石造物のような「底から一定の高さの穴」 | 💭 |
| SPL | すり切りの升を溢れでつないだ列 | 💭 |
| DLY | 底に小さな穴をあけた升・土器 | 💭 |
| ACC | 天秤の吊り皿（土器・木の皿） | ― |
| CMP | 天秤（竿・吊り皿・支柱）。おもりは石や金属の分銅 | 天秤は度量衡の道具 🔍 |
| RTE | 指し樋（竿と同じ軸で振れる竹の樋）と、その下の受け口 | 💭 |
| PIPE | 竹の樋・木樋・石の溝 | 木樋・石樋は飛鳥にある ✅ |
