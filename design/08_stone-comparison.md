## 1. M4：天秤の計算機を石に彫るなら、何が石に残るか 💭

天秤・竿・指し樋・吊り皿は木と竹で作る。石に彫るのは、水を量る・受ける・運ぶ部分だけになる。

| 部品（設計05〜07） | 素材 | 石に残る痕跡 |
|---|---|---|
| 天秤の竿・吊り皿・指し樋 | 木・竹 | 残らない。ただし、支柱を立てる穴・台座の平らな面が石の上か周りに残りうる |
| 升（1u の計量。すり切り） | 石のくぼみでもよい | **同じ容積のくぼみが並ぶ**。縁の高さがそろい、溢れ口（切り欠き）がある |
| 指し樋の受け口 | 石のくぼみ・溝 | **中央と左右に分かれた受け口の組**（XOR：中央＝XNOR、左右＝XOR。左右はどこかで合流する） |
| 信号を運ぶ溝 | 石の溝 | 受け口から次の天秤の皿の真下（または升）へ向かう溝 |
| 捨て溝 | 石の溝 | 計算に使わない水をまとめて外へ出す溝。どこからでも合流できる |
| 駅・控え（カウンタ機械） | 石のくぼみ | 同じ形の「駅」の組が命令の数だけ並ぶ |
| レジスタの皿 | 木・土器（吊るす） | 残らない |

## 2. 予測（天秤版）

設計01 §6 の予測（P1〜P6）に、天秤版の予測（P7〜P10）を足す。

対立仮説（祭祀・庭園）なら：容積に規則性がない／栓の穴がない／流れは一方通行で、見た目の対称性が重視される（設計01 §6）。

## 3. 石について分かっていること

- 確認済みの事実は [HANDOFF.md](../HANDOFF.md) §3。花崗岩、約5.5×2.3×1.0m、東から西へ約5.5度下る。A に注ぐと B → C → D へ流れる。B は底が逆に傾き、水が溜まらない。
- 上面の配置（村上ら2017 の図。欠損部を左右対称に補った**復元の模式図**。実測図ではない）：
  - 東端（高い側）に小さな円いくぼみが4つ：A1 が上、その下に A2（左）・A4（中央）・A3（右）
  - 左右に円いくぼみが3つずつ：BL・CL・DL と BR・CR・DR
  - 中央に長楕円形のくぼみ E（E1・E2）、その下流に F（西端の出口）
  - 中央の溝の西寄りに、大きめの円いくぼみ G（片側だけ）
  - 溝は、A から左右へ斜めに延び（D まで）、B・C はそこから枝分かれでつながる。中央の溝は A4 → E → F
- 二次資料（🔍）：溝は幅約10cm・深さ約5cm、円形・楕円形のくぼみは深さ約10cm。

### P7 の区別のしかた
- **分水口なら**：A1 に注いだ水が、A2・A4・A3 へ**同時に**分かれて流れる。A2〜A4 は A1 より低く、3つとも同じ高さ。
- **指し樋の受け口なら**：A1 は水を受けない（指し樋の真下の目印か、漏斗の座）。A2〜A4 は**互いに仕切られ**、水はどれか1つにしか入らない。
- 日経2014 の「A に注ぐと B → C → D1〜D6 へ流れる」は、**分水口の読み方に合う**（注いだ水が全部へ行く）。これは計算機の仮説に不利な事実として記録しておく。

## 5. 第1回のまとめ（現時点の判定）

- **計算機の仮説だけを支持する特徴は、まだ見つかっていない。** 合いそうな特徴（同じ大きさのくぼみ、3方向に分かれる A 群、中央の出口）は、どれも祭祀・庭園の施設としても説明できる。
- **計算機の仮説に不利な点**：左右の溝が合流しない（P8）、栓・溢れ口・支柱の跡の記録がない（P3・P9・P10）、注いだ水が全部へ流れる（P7 の分水口の読み方）。
- 現在の資料（復元の模式図と二次資料）では、ほとんどの観点が**判定できない**。決め手になるのは実測。
